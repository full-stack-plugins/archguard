# 有依赖关系的澄清

改编自 Matt Pocock grilling；来源与许可保存在插件 `org.partme.guard/sources/`。

先读 [公共协议](references/guard-workflow.md)。已有规格优先。

1. 从目标、已有规格和已确认回答提取开放问题，区分可自行查证的事实与必须由用户决定的取舍。
2. 仓库能回答的问题先查证。存在 CodeGraph 索引则优先查询；没有索引不自动建立。
3. 按问题依赖排序，只问目前能作出决定的一组，通常 1–3 个。提供推荐选项、理由和影响；用户已授权的决定不重复确认。
4. 等待必要回答，同时推进不依赖答案的只读研究。不得把超时当同意。
5. 记录问题、决定、依据、非目标和未解项；写入操作须在授权范围内，落到既有规格的正确位置。
6. 返回确认的决定与剩余阻碍，不能把澄清记录当作审批回执。

结束条件：后续活动所需的关键选择明确；仍不明确的部分有具体问题与责任人，而不是被臆测填满。
