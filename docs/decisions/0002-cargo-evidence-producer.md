# Decision0002 — independent Cargo declaration evidence producer

Status: implemented local library profile, awaiting independent review for4.1/4.2. Legacy CLI remains unchanged. The current profile covers Cargo declaration metadata, not active build features, source-language symbols, an approved architecture baseline or authenticated Git admission.

`ProtectedCargoPolicy::freeze(contract, required_members)` takes an owned controller-selected policy before extraction. It does not authenticate the caller. It caps rule count256, contract128KiB, required members1024 and member/relation identifiers256bytes before constructing expanded scope sets. Required members include rule endpoints; missing endpoints and unsupported relations remain partial, never an empty-graph success. The profile digest includes actual contract and complete required members/relations; coverage has explicit profile/member/relation scopes. Candidate configuration cannot shrink them.

`CargoEvidence::prepare(root, policy, CandidateContext)` copies the existing bounded allowed-root Cargo input into private isolation, discovers the actual trusted tool versions/environment and freezes the enhanced inventory. It then creates the real GE BoundAttempt with that actual inventory digest, producer and initially missing required coverage. `run(cancel)` observes real bounded Cargo metadata against this same isolated input, retains complete dependency declarations, creates native GuardFacts, calls the shared GE evaluate_bounded, finishes the attempt and verifies artifacts. The native `analysis::analyze` function reuses the prepared observation; its facts/digest semantics and original CLI are unchanged.

CandidateContext holds **controller-resolved, unverified local labels/OIDs**. GE validates syntax/completeness. This adapter does not itself prove candidate/base objects exist or that the copied root equals their Git tree; source snapshot is the actual Cargo inventory, not a whole-Git identity. Domain authority is always `controller-resolved-unverified`, advisory=true; no identity/approval provider, signed flag or writer exists. Real read-only GitGuard candidate proof remains task4.4. Tests/export use actual temporary Git objects, but this does not turn the public caller context into production verification. This qualification is material to4.2's full acceptance.

Before successful binding, invalid context/source/policy returns the actual GE TransportDiagnostic; no fabricated OID/envelope. Once bound, Cargo metadata/evaluation/serialization failure yields error/null/no engine artifacts; cancellation yields cancelled/null. Valid missing-member/relation observation yields completed partial/BLOCK/INDETERMINATE. Required scopes cannot change at completion. Cancellation is cooperative at observation boundaries, not instantaneous child interruption. Clock/output transport failure can still return a diagnostic without a completed bundle. Failed observations never expose prior run artifacts.

`archguard.evidence/v1alpha1` is a separate strict bundle with required nullable contract/facts/report/domain plus the actual `guard.integration/v1alpha1` envelope. Native `guard.partme.ai/v1alpha1` schemas are untouched. Artifact references use `artifact://archguard/{contract|facts|report|domain}/{digest}` and digest **compact serde_json Value serialization bytes**; JSON contract bytes are accepted as YAML by GE. `EvidenceBundle::load` and verify check exact versions/fields, mandatory artifacts, engine recomputation/decision, domain reference, declared profile/coverage and declaration-to-fact projection. Artifact deserialization goes through native typed objects before Value normalization, preserving rejection of duplicate/unknown fields. Fields are not authenticated by their hashes.

The domain `archguard.cargo-domain/v1alpha1` attachment retains members, required members/relations, inventory key names, actual manifest/enhanced snapshot digests, binding digest and sorted declarations including rename/dev/build/optional/target/source/path/member-target distinctions. Nullable provenance fields are mandatory. Actual ambient environment values are never emitted; only inventory keys and digests. Nonmember dependencies remain domain declarations, not member-edge facts. No extra unsupported symbol-level capability is declared.

Inputs retain existing runner copy/file/time/output budgets. Artifact serialization stops at GE16MiB; bundle loader is capped at four artifacts plus1MiB envelope. Shared GE evaluate_bounded rejects report amplification before evaluating. A real600-edge Cargo fixture with256rules confirms valid complete facts then actual engine-budget refusal and bound error, rather than a fake empty observation. Unknown/unsupported fields are not silently downgraded.

This slice returns an in-memory bundle only. It adds no file-output endpoint and cannot reuse a previous output file. A developer example exports a new directory for actual cross-consumer fixtures. Existing CLI --report/stdout behavior and safe output handling remain covered by prior tests. CAS, authenticated evidence consumption, real GG binding, cross-consumer admission and published package distribution remain separate tasks. Runner limitations, including lack of OS namespace containment, remain in decision0001; local integrity is not production trust.
