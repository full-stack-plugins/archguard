# Immutable architecture baseline

ArchitectureBaseline is the architecture-owned local revision model. It complements the accepted SG ArchitectureTrace reader and does not create a SpecGuard baseline or change Cargo, Java, or TypeScript analysis. Version: archguard.architecture-baseline/v1alpha1. Production authority provider selection remains unresolved; callers must supply an authenticated external GE AuthorityProvider and protected EligibilityPolicy.

A draft freezes the complete supplied RunBinding, source ref, per-ADR hashes of actual supplied bytes, validated GE contract digest and nonempty required obligation set. Borrowed aggregate serialization is admitted at 1MiB before hashing or cloning, with 256 ADRs, 4,096 obligations and 2,048-byte identifiers. These are immutable content declarations, not proof that caller-supplied source refs are authentic Git objects. Existing GitGuard/SG source binding paths remain responsible for observing source. Drafts grant no authority; GE validates exact structural binding at approval.

Candidate ADR text containing accepted or approved=true is hashed as content only. The model has no Deserialize or public mutable fields. Source/ADR/contract/obligation edits create a new Draft with a new digest and predecessor content digest. The old record and report remain byte-for-byte unchanged. Even removing a previously approved obligation requires a new exact external approval record. Empty obligation sets are rejected rather than treating deletion of all policy as success.

State operations return new immutable records: Draft→InReview via submit; InReview→Approved via approve; Approved→Revoked via revoke; Approved→Superseded via supersede. Invalid transitions fail. Approved replacements must be direct revisions and freshly qualified before superseding. Retired records cannot be revised. Record digests include state, predecessor record, external reference and replacement identity; content digests stay stable across review/approval of the same revision.

External approval uses the existing GE validate_approval_record predicate. Protected policy binding must equal the frozen source RunBinding with baseline_digest set to this content digest; contract_digest must equal the frozen actual contract. Purpose is architecture-baseline, action is architecture-baseline:approve/revoke/supersede as applicable. The provider must authenticate the reference, then GE checks the allowed principal, exact action/purpose/full binding/contract, validity interval and revocation. Provider failure returns a static error. No self-asserted approved Boolean, candidate-supplied principal allowlist, or digest match is authentication.

qualify always re-fetches the external record: expiry, revocation or unavailable issuer means no current approval, while historical serialization and technical report stay unchanged. It returns only approval qualification, not an engine ALLOW or execution permission. Negative controller timestamps fail. Trusted time, protected policy selection and authenticated issuer are explicit caller responsibilities.

This is an immutable model, not a mutable latest-baseline registry. Retiring a record returns its successor; it does not write to the external issuer or invalidate a separately retained historical value by magic. The controller must retain/select its current record and require fresh provider state; external revocation must be reflected by the provider. Concurrent latest-pointer publication, durable storage, remote approval issuance and globally monotone clocks are separate concerns. Old approved records may be retained for audit but must not be selected as current contrary to controller policy. No production provider, network call, baseline file publication or automatic policy relaxation is introduced.

Validation: tests/baseline.rs preserves all existing actual SG/Git/GE trace cases and adds lifecycle/immutable revision, deleted obligation/new approval, exact authorization negatives, retention of historical bytes and borrowed budget tests. All task acceptance is delegated to independent review.
