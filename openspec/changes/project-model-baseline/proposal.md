# 项目统一架构模型与需求增量

## Why
现有 Maven/Cargo 契约检查没有项目领域模型、需求增量或可追溯的模型基线；需求之间的关联无法进入检查与复验。

## What Changes
- 项目维护统一的架构和领域模型，以稳定 ID 表达上下文、模块、业务对象、接口、事件及关系。
- 不可变基线版本与当前指针分离；每个需求保存相对基线的增量和唯一原生规格引用。
- 提供模型校验、影响路径、全项目架构一致性检查、当前输入复验及显式基线更新。
- CLI 负责显式本地更新；MCP 只读；插件方法引用同一基线与需求增量。

## Impact
ArchGuard CLI/插件，GuardEngine 公共方法参考及六工具接入测试。保留现有不使用项目模型的 check/explain/verify 行为与 Maven/Cargo 支持。业务源码级语义推断、自动批准、远端发布不属于此变更。
